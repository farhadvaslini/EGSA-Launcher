# EG:SA — EMPIRE GAME

Android launcher UI prototype.

## Build on GitHub
1. Create a new GitHub repository named `EGSA`.
2. Upload the contents of this folder to the repository root.
3. Open Actions and run **Build EGSA APK**.
4. Download `EGSA-debug-apk` from the successful workflow run.

The PLAY button is a UI prototype. Real game/client connection is not implemented yet.
